# Build plan

SKUL MOGULZ connects student founders with collaborators and early supporters. This file tracks what the MVP was supposed to cover and where things stand.

## Stack

- Web: React + TypeScript + Vite
- API: Node.js + Express + MongoDB
- Realtime: Socket.io
- Mobile: Expo

## MVP checklist

### Foundation

- [x] Repo and app shells
- [x] Database connection
- [x] Auth and roles
- [x] Profiles

### Core product

- [x] Feed
- [x] Create posts / updates
- [x] Categories and filters
- [x] Search basics

### Engagement

- [x] Likes and comments
- [x] Messaging
- [x] Calls
- [x] Media uploads for posts

## Approach

Keep the backend boring and reliable. Ship the web loop first, keep mobile in sync, and only add heavier features once daily usage feels solid.
